# 🎉 Новые функции LAMA

## 1️⃣ Уведомление владельца бота при /admin

### Описание:
Теперь при вызове `/admin` в группе, владелец бота получает уведомление в ЛС!

### Что происходит:
1. Пользователь вызывает `/admin` в группе
2. Бот отправляет уведомление в группу с упоминанием админов
3. **НОВОЕ:** Владелец бота получает детальное уведомление в ЛС

### Формат уведомления владельцу:

```
🚨 ВЫЗОВ АДМИНИСТРАТОРА

👤 Пользователь: Иван (@ivan_user)
💬 Группа: VIP Chat
🆔 Chat ID: -1001234567890
📝 Текст: /admin
⏰ Время: 2025-12-17 15:30:45
```

### Тест:
1. Напиши `/admin` в группе, где добавлен бот
2. Проверь ЛС владельца бота - там будет уведомление

## 2️⃣ Два режима капчи

### Описание:
Теперь капча имеет **4 режима** работы!

### Режимы:

#### `DISABLED` - Капча отключена (по умолчанию)
- Никакой капчи
- Обычное приветствие

#### `JOIN_REQUEST` - Капча при заявке на вступление
- Пользователь отправляет заявку
- Бот отправляет капчу **в ЛС**
- После правильного ответа - заявка одобряется
- После 3 неудачных попыток - заявка отклоняется

#### `AFTER_JOIN` - Капча после вступления в группу
- Пользователь **уже вступил** в группу
- Бот отправляет капчу **В ГРУППЕ**
- Пользователь видит: *"⚠️ Иван, реши капчу за 10 секунд, иначе будешь удалён!"*
- Если не решает вовремя - **автоматический кик**
- Если решает правильно - удаляется сообщение с капчей, отправляется приветствие

#### `BOTH` - Оба режима
- Капча при заявке (в ЛС)
- И капча после вступления (в группе)

## 📋 Настройка режимов капчи

### Получить текущие настройки:

**GET:** `https://lamaplanner.com/api/bots/{bot_id}/welcome`

**Ответ:**
```json
{
  "welcome_enabled": true,
  "welcome_message": "Привет!",
  "join_captcha_enabled": false,
  "captcha_mode": "DISABLED",
  "captcha_timeout_seconds": 10
}
```

---

### Режим 1: Капча при заявке (в ЛС)

**PUT:** `https://lamaplanner.com/api/bots/{bot_id}/welcome`

**JSON:**
```json
{
  "captcha_mode": "JOIN_REQUEST"
}
```

**Процесс:**
1. Пользователь отправляет заявку на вступление
2. Бот отправляет математическую капчу в ЛС
3. Пользователь решает капчу (3 попытки)
4. Если правильно - заявка одобряется автоматически
5. Если неправильно 3 раза - заявка отклоняется

**Тест:**
- Создай группу с ограниченным доступом
- Установи `captcha_mode: JOIN_REQUEST`
- Создай заявку на вступление
- Получишь капчу в ЛС бота

---

### Режим 2: Капча после вступления (в группе)

**PUT:** `https://lamaplanner.com/api/bots/{bot_id}/welcome`

**JSON:**
```json
{
  "captcha_mode": "AFTER_JOIN",
  "captcha_timeout_seconds": 10
}
```

**Процесс:**
1. Пользователь вступает в группу (открытую или по заявке)
2. Бот **сразу** отправляет капчу **В ГРУППЕ**
3. Таймер: 10 секунд (настраивается)
4. Если не решает вовремя - **АВТОМАТИЧЕСКИЙ КИК**
5. Если решает правильно - сообщение удаляется, приходит приветствие

**Настройки таймера:**
- `captcha_timeout_seconds` - от 5 до 300 секунд
- По умолчанию: 10 секунд

**Тест:**
- Установи `captcha_mode: AFTER_JOIN`
- Добавь тестового пользователя в группу
- Капча появится сразу в группе
- Если не решить за 10 секунд - кик

---

### Режим 3: Оба режима сразу

**PUT:** `https://lamaplanner.com/api/bots/{bot_id}/welcome`

**JSON:**
```json
{
  "captcha_mode": "BOTH",
  "captcha_timeout_seconds": 15
}
```

**Процесс:**
1. Пользователь отправляет заявку
2. Получает капчу в ЛС (режим JOIN_REQUEST)
3. Решает капчу, заявка одобряется
4. Вступает в группу
5. Получает капчу В ГРУППЕ (режим AFTER_JOIN)
6. 15 секунд на решение
7. Если решает - приветствие
8. Если не решает - кик

**Тест:**
- Установи `captcha_mode: BOTH`
- Создай заявку
- Реши капчу в ЛС
- Вступи в группу
- Реши капчу в группе за 15 секунд

---

### Отключить капчу:

**PUT:** `https://lamaplanner.com/api/bots/{bot_id}/welcome`

**JSON:**
```json
{
  "captcha_mode": "DISABLED"
}
```

## 🎯 Рекомендуемые сценарии

### Сценарий 1: Максимальная защита от ботов

**Конфигурация:**
```json
{
  "captcha_mode": "AFTER_JOIN",
  "captcha_timeout_seconds": 10,
  "welcome_enabled": true,
  "auto_approval_mode": "AUTO"
}
```

**Процесс:**
- Пользователи вступают свободно (AUTO)
- Сразу получают капчу в группе
- 10 секунд на решение
- Боты не смогут решить - автокик

**Плюсы:**
- ✅ Быстрое вступление
- ✅ Защита от ботов
- ✅ Не нужна модерация заявок

---

### Сценарий 2: VIP группа с двойной проверкой

**Конфигурация:**
```json
{
  "captcha_mode": "BOTH",
  "captcha_timeout_seconds": 15,
  "auto_approval_mode": "CRITERIA",
  "approval_criteria": {
    "required_channels": [-1001111111111]
  }
}
```

**Процесс:**
- Проверка подписки на каналы
- Капча в ЛС при заявке
- Капча в группе после вступления
- Тройная защита!

---

### Сценарий 3: Простая группа без спама

**Конфигурация:**
```json
{
  "captcha_mode": "JOIN_REQUEST",
  "auto_approval_mode": "MANUAL"
}
```

**Процесс:**
- Заявки вручную
- Капча в ЛС перед одобрением
- Спокойная модерация

## 🔧 Технические детали

### Callback данные:

**Капча в ЛС (при заявке):**
```
captcha_{pending_id}_{answer}
```

**Капча в группе (после вступления):**
```
group_captcha_{pending_id}_{answer}
```

### Таймер кика:

Реализован через `asyncio.create_task()`:
1. Отправка капчи → запуск таймера
2. Ожидание `captcha_timeout_seconds` секунд
3. Проверка: решена ли капча?
4. Если НЕТ → бан + разбан (кик)
5. Если ДА → удаление сообщения

### Приветствие после капчи в группе:

Если капча решена правильно:
1. Удаляется сообщение с капчей
2. Вызывается `WelcomeHandler.handle_new_member()`
3. Отправляется обычное приветствие
4. Срабатывает триггер `CAPTCHA_PASSED`

## ⚠️ Важно!

### Для капчи в группе:
- ✅ Бот ДОЛЖЕН быть **администратором** группы
- ✅ Бот должен иметь права на **удаление пользователей**
- ✅ Бот должен иметь права на **удаление сообщений**

### Для уведомления владельца:
- ✅ Владелец бота должен быть зарегистрирован в системе
- ✅ У владельца должен быть привязан Telegram аккаунт
- ✅ Владелец должен написать `/start` боту хотя бы раз

## 🚀 Миграция базы данных

После обновления кода нужно добавить новые поля в таблицу `bots`:

```sql
ALTER TABLE bots 
ADD COLUMN captcha_mode VARCHAR(20) DEFAULT 'DISABLED',
ADD COLUMN captcha_timeout_seconds INTEGER DEFAULT 10;
```

Или пересоздать контейнеры:

```bash
docker-compose down
docker-compose up -d --build
```

## 📝 Обратная совместимость

Старое поле `join_captcha_enabled` продолжает работать:
- `join_captcha_enabled=true` → автоматически `captcha_mode=JOIN_REQUEST`
- `join_captcha_enabled=false` → `captcha_mode=DISABLED`

Но рекомендуется использовать новое поле `captcha_mode`!
